# Dotfiles

Personal configs for Neovim, Vim, Bash, Zsh, tmux, Alacritty, Ghostty, and herdr.
Includes agent skills, rules, extensions, and themes for AI tools, VS Code, and Waterfox.

`sync.sh` copies live configs into this repo.

Polar Aurora uses a neutral `#181818` background with gray surfaces and Aurora accents.
The VS Code theme also works in Cursor; each app's installed theme and appearance settings are tracked separately.
Codex appearance includes its terminal theme and desktop dark colors.
